# AI圆桌lite v0.8.0

- 成员和网页一一对应，不用再点「连接网页」：打开圆桌就自动打开各位成员的网页；添加或换上成员时打开它的网页，移出或换下时关掉；直接关闭某位成员的网页，就等于把它移出圆桌（至少保留两位，保留的那位点名字即可重新打开）。
- 在成员网页里登录、过验证或刷新后，会自动重新检查这一家是否需要登录、额度是否用完，不用再手动点按钮。

---

## 从 0.7.0 升级

点侧栏或记录页顶部的版本号 →「立即更新」。

## 从 0.6.x 及更早版本升级（只需这一次）

下载下面的 `ai-yuanzhuo-lite-v0.8.0.zip`，解压后把文件覆盖到原来加载的那个文件夹里，再到 `chrome://extensions` 点 AI圆桌lite 的刷新按钮。以后的版本就可以一键更新。
