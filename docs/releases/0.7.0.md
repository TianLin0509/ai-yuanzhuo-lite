# AI圆桌lite v0.7.0

- 一键更新：点版本号即可检查更新，有新版时顶部出现「新版本」按钮，点「立即更新」自动下载、核对签名、原地重新加载，圆桌记录和窗口都保留。
- 修复 ChatGPT 10 月改版后「答完了却不提取」：每场第一轮卡在「已发送」、讨论轮认不出提问、代码换行/加粗/表头丢失。

---

## 第一次安装（或从 0.6.x 及更早版本升级，只需这一次）

1. 下载下面的 `ai-yuanzhuo-lite-v0.7.0.zip`，解压到一个普通位置（例如 D 盘或「下载」文件夹，不要放在系统目录）。
2. 已经装过旧版的：把解压出的文件覆盖到原来加载的那个文件夹里，再到 `chrome://extensions` 点 AI圆桌lite 的刷新按钮。这样扩展身份和圆桌记录都保留。
   第一次装的：在 `chrome://extensions` 打开「开发者模式」，点「加载已解压的扩展程序」，选解压出的 `ai-yuanzhuo-lite` 文件夹。

## 以后的版本

点侧栏或记录页顶部的版本号 →「立即更新」。第一次更新时 Chrome 会让你选择扩展所在的文件夹（就是上面加载的那个），之后不用再选。

更新源：GitHub（这台 Chrome 登录了 GitHub 时）→ 备用服务器（自动兜底）。每个文件都核对官方签名，校验不通过不会写入。
