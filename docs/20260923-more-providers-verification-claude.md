# 2026-09-23 新增六家成员与三家回归

基准主干 `4b6b0e442b055212f9b1a7e68033c5daf7d14424`。真实网页测试在独立原生 Chromium（`live-native` Profile，noDefaults 附着，不加测试焦点模拟）中加载本任务构建，由扩展自己的调试支持唤醒后台成员页。测试题、回答与截图只在忽略的 artifacts。

## 范围

成员从三家扩到九家：国内 DeepSeek、Kimi、豆包、千问、元宝；海外 ChatGPT、Claude、Gemini、Grok。每场仍选 2–3 位（与 AI-Arena 的上限一致），侧栏“选择成员”按国内 / 海外分组，选满后其余置灰；新建圆桌沿用最近一次选择。

站点知识参考 AI-Arena 的 `selectors-config.js` 与各站 content 脚本，以及 AI圆桌 Android 的真机记录；选择器全部按 2026-09-23 的真实页面重新核对。AI-Arena 中以下做法没有迁入：

| AI-Arena 做法 | 问题 | lite 的处理 |
| --- | --- | --- |
| 输入后同时派发 Enter 事件，再轮询点击发送按钮 | 两条发送路径可能各发一次 | 核对输入与原文逐字一致后只点击一次 |
| 按钮始终禁用时仍返回“已发送”，交给轮询兜底 | 未发送被当作已发送 | 明确报错，文字留在网页，不自动重试 |
| Claude 检测到“回答等于提问”时自动补发 | 违反“不确定时不自动重发” | 不迁入 |
| 输入框内容达到原文 30% 即视为输入成功 | 截断的提问也会被发送 | 要求完整一致 |
| 找不到回答时按“最大文字块”启发式兜底 | 可能抓到侧栏或别的对话 | 只认本轮提问之后的回答节点 |
| 千问噪音按字符串锚点截断 | 可能截掉正文 | 只在 DOM 层排除推荐卡片，不截断文字 |
| 远程下发选择器 | 属远程配置，本项目不引入 | 不迁入；改版靠适配更新 |

AI-Arena 的 ChatGPT（`data-message-author-role`）、元宝、Grok 选择器在今天的页面上已失效，不能直接复用。

## 通用改动

- 适配器配置化：代码块语言标签、需排除的思考 / 引用 / 推荐节点、回答节点自身的完成标记、未登录标记（发送前拦截，发送后出现注册墙也立即提示）。
- 同一站点的空白首页视为同一位置（如元宝 `/chat` 跳到 `/chat/<agent>`），已保存的对话仍需地址完全一致。
- Slate 编辑器的占位文字与零宽换行标记不再被当成网页草稿。
- 代码块去掉站点渲染的行号与末尾多余空行。

## 实测暴露并修复的问题

| 问题 | 现象 | 修复 |
| --- | --- | --- |
| 豆包 2026-09-23 改版 | 新对话的消息改为 `send_message` / `receive_message`，旧的 `data-observe-row` 不再出现，报“无法确认提问位置” | 两种结构都支持；消息稳定键可来自多个属性 |
