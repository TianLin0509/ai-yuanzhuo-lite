## 独立审查后的修正

- 停止与接棒同时发生：停止在同一事务里给本轮打上“已停止”，并按最新状态停止正在进行的成员；接棒前检查该标记。之后不会再有发送（单测覆盖）。
- 残留清理只针对“本页面里由扩展自己填入、之后没有任何真实键入或粘贴”的文字，且须是本圆桌近期发给该站的提问；用户手敲的相同文字不会被清掉（浏览器测试覆盖，旧逻辑下该步失败）。
- 工作流停在两位之间（如浏览器重启）时，窗口重新认领圆桌后自动接着轮到下一位。
- 撤掉按标签页编号认回“从新对话进入对话”的做法（浏览器重启后编号可能复用）；改为仅在本次发送失败的当下、且标签页仍在本圆桌窗口、网页最新提问与本轮原文一致时，记下网站新建对话的地址，之后按地址精确认回。用户自己打开的对话不会被采纳（单测覆盖两种情况）。关闭窗口时按最新状态停止成员。

## 新功能

- 去掉“同题提问”（与“独立迭代”发送内容相同），旧记录照常显示。
- 工作流：按用户排的顺序串行回答，第 1 位收到问题，之后每位收到问题与前面全部完整回答（可编辑预设，必须保留 {问题} 与 {前面回答}）。出错时停在该成员，重试 / 重新提取 / 跳过后继续；跳过者不提供材料；停止连同排队成员一起停；关闭窗口时排队成员一并停止。浏览器重启后的自动接续由 recover() 处理，未做实测。
- 轻量引导：发送时有成员未连接网页，先提示连接（可选择直接发送）；登录、验证、额度类错误的成员行直接给“打开网页”。
